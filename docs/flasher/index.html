Install in your browser

Flash StickC Motion Face onto an M5StickC straight from Chrome or Edge on a computer - no tools to install.

  1. Connect the StickC with a USB data cable.
  2. Press Install and choose the serial port (USB Serial / FTDI).
  3. Wait about 30 seconds. When it finishes, shake the device!
Your browser does not support Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs HTTPS - open this page from GitHub Pages.

Controls: button A = next character (hold = colour), button B = colour.

Other ways to install (esptool, PlatformIO, M5Burner): see the flashing guide.
